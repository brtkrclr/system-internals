CPU Fundamentals, Visualized

Clock, pipeline, caches, coherence, privilege and the call stack. Every widget is a small, honest simulation; scaled-down ones say so.

2.1Clock Cycle and Frequency Scaling

Every tick of the clock moves the CPU one step. Drag the frequency and watch the cycle time change. Power grows roughly with frequency × voltage², which is why CPUs constantly change both.

Power numbers are illustrative: real voltage/frequency curves differ per chip.

Connection: when nothing is runnable the scheduler runs the idle task (PID 0, 4.5), which puts the core into a C-state.

2.2Pipelining, Branch Prediction, Out-of-Order

Like a laundry: while one load dries, the next washes. Each instruction still takes 5 stages, but one can finish every cycle, until a dependency or a wrong guess gets in the way.

5-stage pipeline

IF fetchID decodeEX executeMEMWB write backflushed

Branch predictor: if (data[i] >= 128) sum += data[i];

A 2-bit saturating counter (a classic textbook predictor; real ones are far more elaborate) guesses each branch from its recent history.

Out-of-order execution

1: load r1, [x]     ; cache miss (scaled: 6 cycles)
2: add  r2, r1, 1   ; needs r1
3: mul  r3, r4, r5  ; independent
4: add  r6, r3, 7   ; needs r3 only

Connection: speculation leaves traces in the cache. That side channel is Spectre and Meltdown, fixed partly by KPTI (3.3).

Write-through vs write-back

Same idea one layer up: the page cache is a write-back cache of the disk (6.7), and fsync() is "evict now".

Connection: MESI is why locks and atomics work across cores (5.3), and why false sharing hurts (1.8).

2.5Buses and DMA

2.6CPU Privilege Levels (Rings)

The CPU itself enforces who may do what. Pick a mode, then try instructions. The only doors from Ring 3 into Ring 0 are ones the kernel set up in advance.

Connection: containers are not VMs: they run in Ring 3 on the same kernel (Part 10). VMs add VMX root/non-root on top of rings.

2.7Function Calls and the Stack

call pushes a return address and jumps; ret pops it. Each call gets a frame. The stack grows down.
