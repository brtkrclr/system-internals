      11.2What If You Press Ctrl+C Halfway?

      The terminal driver in the kernel, not bash, sees ^C and sends SIGINT to every process in the foreground process group: cat and grep, but not bash.

        Connection: process groups and the controlling terminal (4.5), signal delivery on return to user mode (8.1), exit status 128 + 2 = 130 (4.9), stdio buffers that only lived in grep's memory (7.6).
