Containers, Visualized

There is no container object in the kernel. A container is a normal process tree with a restricted view (namespaces), limited resources (cgroups) and restricted privileges (capabilities, seccomp). Switch each piece on and watch the view change.

10.1Namespaces: What Can I See?

Start a shell on the host, then switch namespaces on one by one. Each namespace replaces one global resource with a private copy. Highlighted lines changed.

PID namespaces are nested: one process, two PIDs

Network namespace plumbing: veth pair + bridge + NAT

A new network namespace starts with only lo. The runtime moves one end of a veth pair (a virtual cable) inside as eth0, attaches the other to the docker0 bridge, and NATs outgoing traffic.

Connection: namespaces hang off task_struct->nsproxy (4.2) and are created by clone() flags (4.9); PID 1 inside inherits PID 1's signal rules (3.7, Part 8).
