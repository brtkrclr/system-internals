6.1Physical Memory

RAM is an array of 4 KiB page frames. Free RAM is wasted RAM, so the kernel fills it with page cache and gives it back on demand. Click a frame to see its struct page.

kernelprocess Aprocess Bpage cachefree

    
Scaled down: 64 frames. "available" ≈ free + page cache that can be dropped, the number that matters in free -h.

  

  
Connection: every allocation, mapping, fault and reclaim decision starts by finding the frame (PFN) and updating its struct page (6.2).

6.9Huge Pages and TLB Reach

  
TLB reach = entries × page size. Bigger pages mean one entry covers more memory, and the page walk stops earlier.

  

    

      
      
      
    

    

    

    

  

  
Connection: huge pages need physically contiguous order-9 (2 MiB) blocks from the buddy allocator (6.2), and matter even more inside VMs (2.6).







  
6.10zswap, zram and KSM

  
Trade a little CPU for a lot of RAM: compress pages instead of writing them to disk, or merge identical pages.

  

    
zram: compressed RAM as a swap device

    

      
      
    

    

    

    
zswap is the same idea as a cache in front of a real swap device: compress first, write to disk only when its pool is full.

  

  

    
KSM: four VMs with many identical pages

    

    

    

    
Same letter = same content. Outlined = a merged, shared read-only page.

  

  
Connection: zram is a block device (7.12) used as swap (6.8); a write to a KSM-merged page is an ordinary copy-on-write fault (6.5).
