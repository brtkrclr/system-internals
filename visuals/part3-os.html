3.6Scheduler: Virtual Runtime in Action

Each task's vruntime grows as it runs, scaled by its weight (from its nice value). The scheduler always picks the smallest. Simplified CFS-style model: fixed 4 ms slices; EEVDF adds virtual deadlines on top of this idea.

3.7Boot: From Power-On to a Login Prompt

Each stage's only job is to load the next, bigger stage. Pick BIOS or UEFI and step through.

Partition table: max 4 primary partitions, max 2 TiB. Signature: 0x55 0xAA (2 bytes). 446 bytes is too small for a real boot loader, so stage 1 loads GRUB's core.img.

Connection: PID 1's special rules explain orphans (4.5) and why containers need an init (10.3); initramfs exists because of kernel modules (3.1) and mounts (7.13).
